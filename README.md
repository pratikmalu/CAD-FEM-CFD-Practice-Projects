# CAD / FEM / CFD Practice Projects

Self-directed design and simulation exercises across CAD, FEA, and CFD — built to strengthen skills outside of coursework.

## FEM Simulations
- Disc Brake — Static Structural Analysis
- Disc Brake — Transient Thermal Analysis
- Spur Gear Assembly — Static Stress Analysis
- Heat Sink — Steady-State Thermal Analysis

## CFD Simulations
- Centrifugal Pump — Velocity Flow Analysis
- Office Room Airflow & Thermal Comfort Analysis
- Electronic Circuit Board — Cooling/Airflow CFD (SOLIDWORKS Flow Simulation)

## CAD Design Practice
- Quadcopter Drone Assembly
- Double Wishbone Suspension System
- 4-Cylinder Engine Crankshaft Assembly
- Shock Absorber Assembly
- Valve Body Casting
- Product Design Concepts (headlight, monitor arm mount)

## Tools Used
SolidWorks, SolidWorks Simulation, ANSYS, ANSYS Fluent
